# IT-TICKET-ANALYSIS
📌 Project Overview

The IT Ticket Analysis project focuses on analyzing IT support ticket data to understand ticket distribution, resolution time, agent performance, and customer satisfaction.

The project uses Microsoft Excel to clean and analyze the data, identify trends, and create an interactive dashboard that helps stakeholders make data-driven decisions and improve IT support operations.

🎯 Project Objectives
Analyze overall IT support ticket volume and distribution.
Identify the most frequently reported IT issues.
Evaluate ticket resolution time and trends.
Analyze IT support agent performance.
Understand customer satisfaction levels.
Build an interactive Excel dashboard for better reporting and decision-making.

🔍 Key Insights
1. Ticket Category Analysis

The distribution of IT tickets across categories was:

Category	Ticket Count	Percentage
System	39,002	40%
Login Access	29,193	30%
Software	19,570	20%
Hardware	9,733	10%
Total	97,498	100%

Insight: System and Login Access issues together accounted for approximately 70% of all tickets, making them the major contributors to the IT support workload.

2. Year-wise Ticket Volume
Year	Total Tickets
2016	13,051
2017	14,915
2018	18,954
2019	21,490
2020	29,088

Insight: Ticket volume increased significantly over the period, with 2020 recording the highest number of tickets.

3. Customer Satisfaction

Customer satisfaction improved from approximately 3.98 in 2016 to 4.16 in 2020.

Insight: The increase indicates an improvement in the average satisfaction score over the analyzed period.

4. Resolution Time Analysis

The project examined ticket resolution time to understand support efficiency and identify opportunities to improve issue resolution.

5. Agent Performance Analysis

The analysis compared agent-level ticket handling and satisfaction scores to identify performance variations and potential training needs.

📈 Dashboard Features

The Excel dashboard provides a visual overview of:

Ticket volume and category distribution
Year-wise ticket trends
Resolution time analysis
Agent performance
Customer satisfaction
Interactive filtering using Excel slicers

The dashboard helps users explore ticket data and identify important patterns without manually reviewing all records.

💡 Business Recommendations

Based on the analysis, the following actions may help improve IT support operations:

Investigate recurring System and Login Access issues.
Review resolution workflows to identify opportunities to reduce resolution time.
Provide targeted training and mentoring to agents where performance gaps are identified.
Monitor customer satisfaction regularly.
Use ticket trends to plan IT support resources more effectively.
🏁 Conclusion

This project demonstrates how Microsoft Excel can be used to transform raw IT support data into meaningful business insights.

By analyzing nearly 100,000 IT tickets, the project highlights ticket distribution, year-wise trends, resolution time, agent performance, and customer satisfaction.

The interactive dashboard enables stakeholders to monitor IT support operations and make informed decisions to improve service efficiency.
